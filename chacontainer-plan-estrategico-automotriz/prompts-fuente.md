# Banco de prompts — fuente

Este es el banco de 20 prompts (+ prompt maestro + prompt corto de arranque)
que el usuario compartió para construir el Plan Estratégico de CHACONTAINER
con enfoque automotriz (OEM, Tier 1, Tier 2, manufactura avanzada,
nearshoring). Se conserva aquí como material fuente/referencia.

El documento ejecutivo resultante, construido ejecutando la secuencia
recomendada (18 → 1 → 2 → 3 → 4 → 12 → 6 → 7 → 8 → 20), vive en
[`README.md`](./README.md) de esta misma carpeta.

## Reglas transversales de todo el banco

- No responder de forma genérica; aterrizar todo a CHACONTAINER y al sector automotriz/OEM/Tier 1/Tier 2/nearshoring.
- No inventar cifras, precios finales ni datos internos. Donde falten, marcar **"Dato requerido"** y explicar qué se necesita y por qué.
- Si se requieren números, usar fórmulas o supuestos claramente identificados, no valores inventados.
- Redactar con lenguaje empresarial claro, dividido por secciones, con tablas cuando ayuden a comparar.
- El resultado debe servir como documento base para dirección general / documento convertible a propuesta para inversionistas.

*(El texto completo de cada uno de los 20 prompts, tal como los compartió el
usuario, se conserva en el historial de la conversación — este índice es la
referencia de navegación; no se duplica el texto completo aquí para no
generar dos fuentes de verdad divergentes si el banco se edita.)*
